# AI Resume Analyzer & ATS Score Checker

🚀 **Live Demo:** https://pp-ai-resume-analyzer.netlify.app/

AI-powered Resume Analyzer that reads PDF and image resumes, calculates ATS scores, extracts resume information, detects missing keywords, and provides actionable suggestions to improve resume quality.

## 🌐 Live Website

https://pp-ai-resume-analyzer.netlify.app/

## ✨ Features

- Upload PDF Resume
- Upload JPG / PNG Resume
- Real Resume Parsing
- ATS Score Calculation
- Resume Section Analysis
- Skills Detection
- Keyword Matching
- Missing Keywords Suggestions
- Resume Strength Analysis
- AI-Powered Recommendations
- Responsive Design
- Modern UI/UX
- Dark Mode Support

## 🚀 Installation

```bash
git clone https://github.com/PawanParise/AI-Resume-Analyzer.git

cd AI-Resume-Analyzer

npm install

npm run dev
```

## 📊 How It Works

1. Upload Resume
2. Extract Resume Content
3. Analyze Resume Sections
4. Calculate ATS Score
5. Detect Missing Keywords
6. Generate Suggestions
7. Download Report
